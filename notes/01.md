- 필수 설치 — JDK 17, Maven, VS Code Extension Pack for Java
- 선택 설치 — eGovFrame Initializr (.vsix)
1. [공식 예제 다운로드](https://github.com/eGovFramework/egovframe-boot-sample-java-config)
2. 폴더 명을 프로젝트 명으로 설정 후 Open Folder
3. 필요 시 [application.properties](../src/main/resources/application.properties)에서 포트 번호 변경
    ```
    server.port=8082
    ```
4. 서버 실행 확인
    ```
    mvn spring-boot:run
    ```
5. `http://localhost:8082` 접속 후 동작 확인
---
- dataSource
    - 자바 코드가 DB에 연결할 때 사용하는 객체
- Mapper
    - 자바 메서드와 SQL을 연결하는 역할
- MyBatis
    - 자바 코드에서 SQL을 실행하고, 그 결과를 자바 객체로 돌려주는 라이브러리
```
서비스 → Mapper 호출 → MyBatis가 dataSource에서 DB 연결을 받아 SQL 실행 → 결과 반환
```
6. 패키지 이동
    - `src/main/java/com/erp/`
        - EgovBootApplication.java 실행 클래스 이동
    - `src/main/java/com/erp/config/`
        - 기존 설정 7개 이동
        ```
        제외 파일
        EgovConfigAspect.java       기본 예외 처리 유지
        EgovConfigIdGeneration.java AUTO_INCREMENT 사용
        ```
    - `src/main/java/com/erp/pagination/`
    - `reference/sample-tests`
        - `src/test/java/egovframework/example`의 예제 전용 테스트 코드 이동
7. pom.xml 수정
    ```
    <groupId>com.erp</groupId>
	<artifactId>erp</artifactId>
    <name>erp</name>
    ```
8. 파일 수정
    - [`EgovBootApplication.java`](../src/main/java/com/erp/EgovBootApplication.java) 한국 표준시 초기화
    - [`EgovConfigDatasource.java`](../src/main/java/com/erp/config/EgovConfigDatasource.java) 외부 설정 주입
    - [`EgovConfigMapper.java`](../src/main/java/com/erp/config/EgovConfigMapper.java) Mapper, XML 검색 범위 확장
    - [`EgovConfigTransaction.java`](../src/main/java/com/erp/config/EgovConfigTransaction.java) @Transactional을 쓸 수 있게 준비
    - [`EgovConfigWeb.java`](../src/main/java/com/erp/config/EgovConfigWeb.java) Thymeleaf 캐시 비활성화
    - [`EgovConfigProperties.java`](../src/main/java/com/erp/config/EgovConfigProperties.java) pageUnit 변경
