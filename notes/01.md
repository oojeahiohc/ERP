### 1. eGovFrame 샘플 실행
- 필수 설치: JDK 17, Maven, VS Code Extension Pack for Java
- 선택 설치: eGovFrame Initializr (.vsix)
1. [공식 예제 다운로드](https://github.com/eGovFramework/egovframe-boot-sample-java-config)
    - Code - Download ZIP
2. 폴더 명을 프로젝트 명으로 설정 후 Open Folder
3. 필요 시 [application.properties](../src/main/resources/application.properties)에서 포트 번호 변경
    ```
    server.port=8082
    ```
4. 서버 실행 확인
    ```
    mvn spring-boot:run
    ```
5. `http://localhost:8082` 접속 후 동작 확인

### 2. 패키지 이동 및 예제 테스트 보관
#### 용어
- dataSource
    - 자바 코드가 DB에 연결할 때 사용하는 객체
- Mapper
    - 자바 메서드와 SQL을 연결하는 역할
- MyBatis
    - 연결된 SQL을 DB에 실행하고 조회 결과를 자바 객체로 변환하는 라이브러리
```
서비스 → Mapper 호출 → MyBatis가 dataSource에서 DB 연결을 받아 SQL 실행 → 결과 반환
```

    ### 3. 오류 처리 코드
    1. [`Errors.java`](../src/main/java/com/erp/common/Errors.java) 업무 오류를 공통 형식으로 만드는 클래스
        - `ResponseStatusException`
            - HTTP 상태 코드와 안내 문구를 담을 수 있는 Spring의 런타임 예외. 
            - try-catch와 throws 선언이 필수가 아니며 웹 요청 처리 중 이 예외가 catch로 처리되지 않고 Spring MVC까지 올라오면, Spring MVC가 @ControllerAdvice로 등록된 GlobalExceptionHandler에서 예외 타입에 맞는 @ExceptionHandler 메서드를 호출한다.
    2. [`Forms.java`](../src/main/java/com/erp/common/Forms.java) 화면에서 받은 입력값을 서버에서 검사하는 공통 클래스
    3. [`GlobalExceptionHandler.java`](../src/main/java/com/erp/common/GlobalExceptionHandler.java) 컨트롤러에서 발생한 예외를 받아, 예외 유형에 맞는 HTTP 상태와 안내 문구를 공통 오류 화면으로 전달하는 클래스
    - 입력 검증 실패: `Forms`가 필드별 오류를 모아 `Errors.http()`로 HTTP 400 예외를 만들어 던진다. Spring MVC는 예외를 `GlobalExceptionHandler`에 전달한다.

    - 업무 규칙 위반: 컨트롤러나 서비스가 `throw Errors.http(...)`로 예외를 던지거나, `Errors.check()`가 조건 위반 시 HTTP 409 예외를 던진다. Spring MVC는 예외를 `GlobalExceptionHandler`에 전달한다.
